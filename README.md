Шелаев Серафим М8О-408Б-22  
Нужно разрушить крепость из пушки. Игрок перемещает пушку по карте, передает  ей координаты  крепости и заряжает разными снарядами . Сложность в том, что пушка может находится только в определенных зонах местности, которые регулярно меняются. Каждая зона имеет свои погодные  условия и ландшафт. В зависимости от этого игроку нужно выбирать оптимальный вид снарядов и подстраиваться с правильной передачей координат крепости. Юудет визуализация взрывов-попаданий по крепости и визуализация полета снарядов.
